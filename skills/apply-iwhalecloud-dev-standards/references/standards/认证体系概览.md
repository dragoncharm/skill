## 岗位能力认证概览及说明

此说明对已发布的岗位能力认证的认证项及面向角色和考试范围提供概览，并进行相关指导和说明。<br>
岗位能力认证遵从[《关于开展岗位能力认证的规定》](https://iknow.iwhalecloud.com/sites/training/train/_layouts/15/WopiFrame.aspx?sourcedoc={f84c27c2-718f-49a9-b4ff-6e99e70c7f81}&action=default)的要求，属于公司必选认证，认证项由HRBP根据员工工作中使用的技能进行分配，每个认证项认证通过后有效期一年，到期后如仍在从事相关工作则需要重新认证。根据所需技能的必要性，分为主认证、副认证。根据已配置认证项已完成认证的次数，分为首次认证、再次认证。<br>
任一认证项的认证周期内未取得及格记录的，视为该认证项该认证周期认证不通过。**<font color="red">认证不通过者遵循以下管理要求。考试舞弊行为触犯诚信红线，一经发现，公司立即与该人员解除合同关系。</font>**

| 主/副认证 | 首次/再次认证 | 管理要求 |
| ---- | ---- | ---- |
| 主认证 | 首次认证 | 三次考试机会内必须通过。<br>未转正人员未通过认证，<font color="red">不予以转正</font>；<br>已转正人员未通过认证，<font color="red">优先以辞退进行处理</font>。|
| 主认证 | 再次认证 | 必须通过。<br>三次考试机会内未通过的，系统会自动追加一个可考月份，<font color="red">每追加一个，该月月度绩<br>效工资下浮1000元，直至取得及格记录为止系统不再自动追加可考月份</font> 。|
| 副认证 | 首次认证 | 无公司级要求。<br>由各级团队自定管理标准，三次考试机会内未通过的，系统会自动追加一个可考月份，<br>直至取得及格记录为止系统不再自动追加可考月份。 |
| 副认证 | 再次认证 | 无公司级要求。<br>由各级团队自定管理标准，三次考试机会内未通过的，系统会自动追加一个可考月份，<br>直至取得及格记录为止系统不再自动追加可考月份。|
